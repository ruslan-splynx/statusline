# statusline

Анімований статуслайн для [Claude Code](https://code.claude.com) у два рядки: модель, git, гроші, контекст, ліміти й кеш.

```
⠙ Opus 5 high │ ▸ ~/GitHub/statusline │ ⎇ main ✓ │ ◷ 45m  +412/-57 │ 💰$4.37  1h $4.37 ($5.78)  10m $0.97 ($2.38)  rate $5.81/h
ctx ████░░░░░░░░ 34% 340k/1.0M │ 5h ██████▏░░░ 62% ⟳2h06m │ 7d █████████▎ 93% ⟳3d11h │ cache ● 94% 36m │ api 14m
```

## Що показує

**Рядок 1**

| Поле | Значення |
|---|---|
| `⠙ Opus 5 high` | спінер, модель, effort, `⚡fast` у fast mode |
| `▸ ~/…/dir` | поточна папка |
| `⎇ main +2 ~3 ?1 !1 ↑1 ↓2` | гілка, staged, modified, untracked, конфлікти, ahead, behind (`✓` якщо чисто) |
| `⇅ #123` | відкритий PR, клікабельний (колір означає review state) |
| `◷ 45m  +412/-57` | тривалість сесії, додані/видалені рядки |
| `💰$4.37` | вартість поточної сесії |
| `1h $4.37 ($5.78)` | витрати за останню годину: ця сесія (усі сесії разом) |
| `10m $0.97 ($2.38)` | те саме за 10 хвилин |
| `rate $5.81/h` | середня вартість години цієї сесії (з'являється через 5 хв) |

**Рядок 2**

| Поле | Значення |
|---|---|
| `ctx` | заповненість контекстного вікна, токени |
| `5h` / `7d` | 5-годинний і тижневий ліміти підписки, `⟳` означає час до скидання |
| `spend` | ліміт витрат (лише через gateway) |
| `cache ● 94% 36m` | prompt cache: `●` теплий / `○` холодний, % токенів із кешу, скільки ще проживе |
| `api 14m` | скільки часу модель реально генерувала відповіді |

### Кольори й попередження

- **Контекст `ctx`**: зелений → жовтий до 40%, **оранжевий від 40%**, **червоний і блимає від 60%**.
- **Ліміти 5h/7d**: зелений → жовтий до 80%, **оранжевий від 80%**, **червоний і блимає від 90%**.
- **Гроші поточної сесії**: `10m` більше **$10** або `1h` більше **$50** стають червоними й блимають.
- **Кеш**: блимає, коли до протухання лишається менше хвилини. Якщо дати кешу протухнути, наступне повідомлення перезапише весь контекст за ціною запису в кеш.

Анімація (спінер, відблиск на барах, блимання) іде 1 кадр/с, бо частіше Claude Code статуслайн не оновлює.

## Встановлення

Потрібен лише Node.js 18+ (`brew install node`). Інших залежностей немає.

```bash
git clone https://github.com/ruslan-splynx/statusline.git ~/GitHub/statusline
```

Додай у `~/.claude/settings.json` (шлях до `node` підстав свій, дізнатися можна через `which node`):

```json
{
  "statusLine": {
    "type": "command",
    "command": "/opt/homebrew/bin/node ~/GitHub/statusline/statusline.js",
    "padding": 0,
    "refreshInterval": 1
  }
}
```

`refreshInterval: 1` потрібен для анімації й живих таймерів. Без нього статуслайн оновлюється лише на подіях.

Перезапусти `claude`.

### Nerd Font іконки

Якщо в терміналі стоїть [Nerd Font](https://www.nerdfonts.com), можна ввімкнути гарніші іконки:

```json
"command": "STATUSLINE_NERD=1 /opt/homebrew/bin/node ~/GitHub/statusline/statusline.js"
```

## Як рахуються витрати за 1h / 10m

Claude Code передає лише загальну вартість сесії. Тому скрипт на кожному оновленні пише знімок `(час, сесія, вартість)` у `~/.claude/statusline/cost-log.jsonl` (зберігаються останні 6 годин). Витрати за вікно дорівнюють сумі приростів вартості в цьому вікні: окремо для поточної сесії і по всіх сесіях разом. Звідси висновки:

- історія накопичується з моменту встановлення, тож перші хвилини цифри приблизні;
- якщо сесія почалась до встановлення, її вартість розподіляється рівномірно на її тривалість;
- `/clear` обнуляє вартість сесії, і це враховується коректно.

Git-статус кешується на 5 секунд у `~/.claude/statusline/git-cache.json`, щоб щосекундні оновлення лишались дешевими (~40 мс на рендер).

## Перевірка без Claude

```bash
STATUSLINE_DRY=1 node statusline.js < sample.json
```

`STATUSLINE_DRY=1` вимикає запис у лог витрат, щоб тестова сесія не потрапила в суми в дужках.
